# @mosaicstack/hello-mosaic

Test package for MosAIc SDK publishing workflow.

## Installation

```bash
npm install @mosaicstack/hello-mosaic
```

## Usage

```javascript
const { helloMosaic } = require('@mosaicstack/hello-mosaic');

console.log(helloMosaic()); // "Hello from MosAIc SDK!"
```
